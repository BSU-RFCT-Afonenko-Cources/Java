# Программирование на Java

Учебная книга и исследовательские рефераты по Java. Общее оформление БГУ подключается через отдельную тему. Книга расположена в `book/`, рефераты — в `essay/`; материалы письменного контроля — в `test/`.

Для сборки сайта используются актуальные стабильные Quarto и CUE. Расширения включены в репозиторий.

```sh
quarto render --profile student
quarto render --profile full
quarto preview --profile student --no-browser --port 4200
quarto run tests/check-publication.ts
```

Студенческий сайт создаётся в `_site-student/`, полная версия — в `_site-full/`. Главная страница открывает книгу, рефераты доступны в `essay/`. Письменные задания собираются отдельно командой `quarto render test` в PDF; для них нужны LuaLaTeX и шрифты Computer Modern Unicode (CMU).

Внутри книги используются стандартные ссылки Quarto `@sec-id`, между книгой и рефератами — `@book:sec-id` и `@essay:sec-id`. Профили определяют состав публикации; исходники и история открытого репозитория доступны независимо от профиля.

Публичный каталог `reference-catalog.json` содержит только явно перечисленные
главы книги. Их состав задан в `reference-catalog.exports.book`; внутренние
подразделы, задания и решения остаются доступными для ссылок внутри курса.
После добавления главы включите её ID в этот список, если на неё должны
ссылаться другие курсы.

Авторский формат сверяется с действующими примерами
[шаблона курса](https://github.com/Afonenko-Course-Tools/quarto-template-course).
CI проверяет используемые учебные блоки, шорткоды, расширения, настройки
оценивания и отдельные PDF-проекты, затем собирает оба представления на
стабильном и предварительном выпусках Quarto. Новую возможность сначала
показывайте работающим примером в шаблоне.

Учебную модель проверяет `course-core`, ссылки разрешает `reference-catalog`,
а сборку подпроектов выполняет `project-publish`. Стартовые проекты собирает
`project-download` из явно перечисленных каталогов; преподавательские архивы
разрешены только для профиля `full`. PrairieLearn явно подключён только в книге
рефератов через `course.adapters` и соответствующий фильтр. Адаптер описывает
задания; экспорт на платформу и компиляторы в этот этап не входят.

Обработчики сборки и стили перечислены в YAML. Чтобы отказаться от оформления БГУ,
удалите `metadata-files: [_bsu.yml]` в книге и рефератах; авторская разметка
не требует изменений. Источники установленных пакетов зафиксированы в `UPSTREAM.md`.
