# Программирование на Java

Учебная книга и исследовательские рефераты по Java. Книга расположена в `book/`, рефераты — в `essay/`; материалы письменного контроля — в `test/`.

Для сборки сайта нужны Quarto ≥ 1.10 и CUE ≥ 0.17. Рабочий путь не должен содержать пробелов. Расширения включены в репозиторий.

```sh
quarto render --profile student
quarto render --profile full
quarto preview --profile student --no-browser --port 4200
```

Студенческий сайт создаётся в `_site-student/`, полная версия — в `_site-full/`. Главная страница открывает книгу, рефераты доступны в `essay/`. Проект `test/` собирается отдельно.

Внутри книги используются стандартные ссылки Quarto `@sec-id`, между книгой и рефератами — `@book:sec-id` и `@essay:sec-id`. Профили определяют состав публикации; исходники и история открытого репозитория доступны независимо от профиля.
